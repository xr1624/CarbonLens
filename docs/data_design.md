# CarbonLens 資料設計

持股與基準的碳強度以 `tCO₂e / USD million revenue` 表示，排放範疇採用 `Scope 1 + Scope 2`。使用者可選擇合成示範基金，或上傳 CSV 並透過案件表單補充基金資料與原始宣稱。兩種來源都走同一套驗證與計算規則。

## CSV 欄位

CSV 採 UTF-8，可含 BOM。識別碼以文字讀取以保留前置零。數值欄接受以 `.` 為小數點的有限定點十進位數，例如 `25.5`，表示百分比的欄位以 `25.5` 表示 25.5%。請將科學記號與千分位轉為定點數字後再上傳。為限制極端輸入的運算成本，數字最多 128 位，符號與小數點另計。欄名使用下列拼法，缺欄、重複欄名及讀取錯誤會回報對應檔案和問題。空白值保留為缺漏。

### `funds.csv`

| 欄位 | 型別與用途 |
| --- | --- |
| `fund_id` | 非空文字，同一資料集內唯一。 |
| `fund_name` | 非空文字，供介面與報告顯示。 |
| `esg_claim` | 非空文字，保留原始宣稱，供 AI 擷取及人工查證。 |
| `benchmark_id` | 非空文字，指定資料集中的基準識別碼。 |
| `report_year` | 四位數整數，基金宣稱所屬報告年度。 |
| `claimed_reduction_pct` | 合成測試的標準答案，必要欄位。使用者提供的真實資料可留空。 |

AI 擷取的輸入是 `esg_claim`。標準答案欄位只在測試比對時使用，排除於模型輸入、人工覆核初始值及正式判定。

### `holdings.csv`

| 欄位 | 型別與用途 |
| --- | --- |
| `fund_id` | 非空文字，對應 `funds.csv` 中的基金。 |
| `company_id` | 非空文字，與 `fund_id` 共同識別一筆持股。 |
| `company_name` | 非空文字，供圖表與證據明細顯示。 |
| `sector` | 非空文字，供產業分布圖依實際權重加總。 |
| `weight_pct` | 有限數值，範圍為 0 到 100，整檔基金合計須等於 100。 |
| `carbon_intensity_tco2e_per_usd_million_revenue` | 有限且非負的碳強度。空白代表缺漏，明確提供的 `0` 為有效值。 |
| `data_year` | 四位數整數，須符合案件的 `report_year`。 |
| `emission_scope` | 文字，須使用 `Scope 1 + Scope 2`。 |

欄名已指定持股碳強度的單位。案件輸入介面應標示單位，讓上傳者確認來源採用同一單位。CSV 本身無法證實來源數值已做正確換算。

### `benchmarks.csv`

| 欄位 | 型別與用途 |
| --- | --- |
| `benchmark_id` | 非空文字，供基金及案件引用。 |
| `benchmark_name` | 非空文字，供證據顯示與宣稱基準比對。 |
| `data_year` | 四位數整數，須符合案件的 `report_year`。 |
| `emission_scope` | 文字，須使用 `Scope 1 + Scope 2`。 |
| `waci` | 有限數值，須大於 0。 |
| `waci_unit` | 文字，須使用 `tCO₂e / USD million revenue`。 |

每組 `benchmark_id`、`data_year`、`emission_scope` 最多一筆。找不到識別碼時回報缺少基準。識別碼存在但當年或指定排放範疇沒有對應資料時，回報年度或範疇不符。宣稱中擷取的基準名稱須與選用基準可核對，名稱有歧義時交由人工確認。

## 驗證順序與結果

1. 檢查三份檔案的格式與欄名，依所選基金識別碼驗證基金、持股與相符基準。不同基金的持股不進入本案。若找不到本案持股或同案 `company_id` 重複，回報問題。CSV 載入時保留實體起始列號，分析前若篩選資料表須保留原始索引以維持來源對照。
2. 檢查權重有限且非負、總和等於 100%。以原始十進位數值加總。權重合計不符時保留原始權重供修正。
3. 檢查每列碳強度，並計算權重覆蓋率。檢查報告年度、各筆持股年度、基準年度、排放範疇與單位是否一致。驗證基準 WACI 大於 0。
4. 檢查擷取的目標是否為原始文字可核對的單一百分比，且介於 0% 至 100%。核對比較基準與適用年度。無法確認時，保留文字證據並要求人工確認。
5. 每個問題記錄受影響的檔名、列識別碼、欄位、觀察值與補件方式。資料缺漏或不可比較時，規則結果為「資料不足，無法判定」。資料可比較而宣稱待確認時，執行狀態為「等待宣稱確認」，暫不產生數值判定。

### Data Coverage

以持股權重計算，分子為具有有效碳強度的持股權重總和，分母為案件持股的權重總和。兩者相除後乘以 100 即為覆蓋率。持股重複、無持股、權重有無效值或總和為 0 時，覆蓋率顯示為無法計算。權重可加總但總和不等於 100% 時，覆蓋率仍可用於定位缺漏，案件依然無法判定。

年度、範疇與單位的相容性另行驗證。因此即使覆蓋率為 100%，案件仍可能缺少可比較資料。若有缺漏的碳強度，包括權重為 0 的列，案件須補件。覆蓋率回傳至多 28 位有效數字，向零截斷以保留不足 100% 的差異。覆蓋率不足 100% 時，基金 WACI 與實際降低比例皆留空。

### WACI 與判定

```text
基金 WACI = Σ[(weight_pct / 100) × 企業碳強度]
實際降低比例 (%) = (基準 WACI − 基金 WACI) / 基準 WACI × 100
```

通過完整性及可比較性檢查且宣稱已確認後，由 Python 計算上述數值。權重與碳強度以十進位數讀取，計算與門檻比較使用精確分數。等於目標時為「符合宣稱」，低於目標時為「宣稱不一致，需人工覆核」。結果中的實際降低比例保留至多 28 位有效數字，可以為負，表示基金 WACI 高於基準。接近門檻的案例若顯示值因捨入看似相等，仍以精確比較得出的判定為準。

## 案件證據與版本

案件快照保存輸入來源標記、基金資料、原始宣稱、持股及實際引用的基準資料。分析紀錄連結輸入快照，保存擷取欄位與原文引句、驗證問題、逐筆 WACI 貢獻、公式、年度、排放範疇及規則版本。未通過驗證的案件保存其可取得的證據與補件清單。

人工覆核紀錄連結案件與分析版本，保存原始欄位值、修改值、覆核動作、時間與意見。人工修正擷取欄位時，引用支援修正值的原文。如果須修正宣稱來源，新增輸入快照。每次修正後重新驗證並依確定性規則計算，保留歷次結果供追溯。匯出報告以當次分析及其覆核紀錄為準。
