# CarbonLens 使用說明

1. 「分析總覽」顯示目前可存取的案件。
2. 「建立案件」可選 Synthetic Data 示範基金。選擇市場基準指數，再核對 ESG 宣稱原文。
3. 人工輸入模式需要填寫比例並勾選核對；Mock Mode 使用示範規則；Real 需要授權登入與有效 API 額度。
4. 自有 CSV 上傳需要登入，三份檔案各不超過 10 MB、10,000 筆，須為 UTF-8 並包含範本必要欄位。
5. 結果顯示 WACI、降低比例、覆蓋率、圖表與來源列。資料不足或宣稱缺乏證據時，不會產生可比較的結論。
6. 展開模型擷取及 Agent 工具執行紀錄檢查流程。
7. 人工覆核須填寫意見。修正須提供原文中的比例、基準、年度和逐字證據，系統重新計算並保留覆核紀錄。
8. 下載 JSON 保存輸入快照、精確數值與完整紀錄；Markdown 報告提供摘要。
9. Real 重新執行會使用新的模型額度。API 錯誤時先檢查設定，避免連續重試。

訪客案件只存在目前工作階段。登入案件依帳號隔離；未設定外部資料庫時使用 SQLite，Community Cloud 重啟可能遺失紀錄，請下載檔案保存。跨重啟保存需由管理者設定 PostgreSQL DATABASE_URL。
